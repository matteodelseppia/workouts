# Week 1 Calisthenics Program

## 1. Program Overview

Primary objective: accumulate repeatable strength and hypertrophy work without sacrificing elbow or shoulder health. Skill exercises stay frequent but submaximal—clean practice, not tests.

Week 1 runs from **Sunday, September 20 through Saturday, September 26, 2026**.

### Split logic

- **Sunday:** highest-priority heavy bar-dip session.
- **Tuesday:** handstand-push-up strength and unilateral pulling.
- **Wednesday:** muscle-up practice plus weighted ring strength.
- **Thursday:** lower-fatigue pin-chin, HSPU, and skill work.
- **Saturday:** short pull/skill primer. No pressing or muscle-ups, preserving the shoulders and triceps for Sunday.
- Most exercises receive only 1–3 sets per exposure, spreading stress across the week.
- Unless otherwise stated, stop every set with pristine technique. **RPE 7 ≈ 3 reps in reserve; RPE 8 ≈ 2 reps in reserve.**

### Week 1 schedule

| Day | Main training | Running |

| **Sun, Sep 20** | Heavy bar dips, weighted chin-ups, L-sit pull-ups | None scheduled |
| **Mon, Sep 21** | Upper-body rest | Main moderate/quality run |
| **Tue, Sep 22** | HSPU, archer chins, scapular pulls, front-lever hold | None |
| **Wed, Sep 23** | Muscle-up, weighted ring pull/dip, front-lever raises | Optional short easy run after lifting |
| **Thu, Sep 24** | Pin chins, HSPU back-off, L-sit pull-ups, front-lever hold | None |

### Weekly volume

Ramp-up sets are excluded. “Productive” sets are approximately RPE 7–8; technique work is deliberately easier.

| Movement pattern | Productive sets | Easier skill/back-off work | Comment |
|---|---:|---:|---|
| Vertical push | **9** | 2 | Bar dips 3, Tuesday HSPU 3, ring dips 3; Thursday HSPU 2 |

This gives **9 productive pushing sets versus 11 productive pulling sets**, appropriate for the pull-dominant skill goals. The additional pulling is low-fatigue technique work rather than failure-oriented hypertrophy volume.

## 3. Progression & Deload Rules

### Global progression rules

- Progress only when every prescribed work set remains technically clean and within the RPE ceiling.
- Increase **reps before load** when a rep range is given.
- Add only one variable at a time: reps, load, lever difficulty, hold duration, or reduced band assistance.
- If performance falls by more than one rep or RPE rises by roughly one point, repeat the previous week rather than forcing progression.
- A failed repetition does not count and should not be immediately retried.

### Exercise-specific progression

| Exercise | Progression method |
|---|---|
| Weighted bar dips | Progress from 3×3 toward 3×4 by adding only **one total rep per Sunday**. After 3×4 is clean at ≤RPE 8 for two exposures, add 1–2.5 kg and return to 3×3. |
| Weighted chin-ups | Double progression over 2×5–7. Once 2×7 is achieved at ≤RPE 8, add 1.25–2.5 kg and return to 2×5. |
| Weighted pin chin-ups | Progress over 2×3–5. Add load only after both sets reach five clean dead-stop reps. |
| Weighted HSPU | Build Tuesday from 3×3 to 3×5. After 3×5 is repeated cleanly, add the smallest practical load. Thursday follows Tuesday and is not progressed independently. |
| Ring weighted pull-ups | Double progression over 3×3–5, then add 1–2.5 kg. Maintain identical ring height and turnout. |
| Ring weighted dips | Double progression over 3×3–5. Add only 1–2 kg after 3×5 is stable and pain-free. |
| Front-lever raises | Build each set from four to six reps. Advance the lever only when Wednesday and Saturday are both clean; return to four reps after changing leverage. |
| Front-lever holds | Add approximately one second per set until all four weekly sets reach 10 seconds. Then slightly lengthen the lever and return to 6–7 seconds. |
| Archer chin-ups | Progress Tuesday toward 2×4/side. Then increase the reach or reduce assistance and return to two reps. Saturday remains an easy rehearsal. |
| Band-assisted muscle-up | Earn four perfect singles with the 15 kg band for two consecutive weeks. Then reduce assistance modestly and return to three singles. |
| One-arm scapular pull-ups | Build Tuesday toward 2×6–8/side, then add a longer pause. Do not rush to external loading. |
| L-sit ring pull-ups | Add one rep to one weekly set at a time until all five sets reach five reps. Then improve the L position or add minimal load and return to triples. |

### Deload

Use a default rhythm of **four building weeks followed by one deload week**. A fifth building week is acceptable only if performance and joints remain consistently good.

During the deload:

- Reduce total work sets by approximately 40–50%.
- Reduce external loads by 10–15%.
- Keep every set at RPE 6 or below.
- Use an easier front-lever position.
- Perform only two easy muscle-up singles with a stronger band.
- Perform bar dips as 2×3 with 15–20% less external load. If there is shoulder, elbow, or sternal irritation, omit external loading that week.

Deload early if two consecutive sessions show reduced performance, persistent tendon stiffness, disturbed sleep, or joint discomfort that worsens during warm-ups.

## 4. Running Integration

The default is two runs, with a third optional run:

1. **Monday — main run:** 35–50 minutes. This can include the week’s moderate tempo or controlled intervals because the legs are otherwise untrained.
2. **Wednesday — optional third run:** 20–30 minutes at conversational effort. Perform it after calisthenics, never before the muscle-up and ring work.
3. **Friday — easy run:** 30–45 minutes at conversational effort. Keep it aerobic and finish feeling capable of continuing.

If strength and running occur on the same day, separate them by at least six hours when convenient. If they must be consecutive, perform calisthenics first and keep the run easy.

Avoid:

- Long or hard running on Friday.
- Any scheduled run on Saturday.
- Hard running immediately after Sunday’s heavy dips.
- Increasing running distance and weighted-calisthenics volume in the same week.

This arrangement leaves Saturday low-fatigue and provides roughly 36–48 hours between Friday’s easy run and the next heavy dip session.

## 5. Coaching Notes & Injury Prevention

### Weighted bar dips

- Use parallel, non-wobbling bars and ensure the belt/load hangs centrally.
- Begin with the shoulder blades gently depressed; do not force them aggressively backward.
- Keep the elbows tracking naturally about 30–45° from the torso.
- Descend under control for approximately two seconds. Use only the deepest range that remains stable and free of anterior-shoulder or sternal discomfort.
- No bouncing out of the bottom, asymmetrical lockouts, or grindy final reps.

### Weighted ring dips

- Establish support with the rings close to the body before beginning the descent.
- Allow a small natural ring rotation, but do not let the hands suddenly shoot outward.
- Keep forearms approximately vertical and lower only while the shoulders remain centered.
- End the set as soon as ring instability increases. Stability failure is failure, even if another rep could be muscled through.

### Wall weighted HSPU

- Secure the external load so it cannot shift during the repetition.
- Use a stable tripod between both hands and the head; let the head travel slightly forward rather than dropping straight between the hands.
- Keep ribs and pelvis stacked rather than excessively arching the lumbar spine.
- Finish each repetition with a strong overhead shrug. Stop if pressing becomes asymmetrical.

### Protecting strength while developing skills

- Muscle-ups remain first on Wednesday because transition quality is highly fatigue-sensitive.
- Front-lever and L-sit work stays mostly at RPE 6–7. The goal is frequent perfect exposure, not accumulating failed positions.
- Never test maximum lever length, band assistance, and weighted pulling performance in the same week.
- If elbow irritation appears, first remove Saturday archers and reduce L-sit volume; preserve the primary weighted pulls if those remain pain-free.
- Sharp pain or discomfort that worsens from set to set is a stop signal, not something to train through.

The optional external rotations, wrist-extensor eccentrics, and scapular push-up plus are the only additions outside the provided pool. They support cuff, elbow-tendon, and serratus/scapular function and should never be taken near failure.

## 6. Assumptions Made

- Normal session availability is **75–90 minutes**, including warm-up and ramp sets. Saturday is intentionally shorter.
- There is no dedicated lower-body strength training; running is currently the only leg training.
- You are free of an active shoulder, elbow, wrist, or sternal injury.
- The listed performances are repeatable work sets, not recent maximal-effort tests.
- Because the load used for weighted HSPU was not supplied, it is selected using the stated RPE.
- “15 kg band” refers to the same band and attachment setup each week; band labels do not represent exact assistance throughout the movement.
- Week 1 begins with reasonable recovery. If today follows hard upper-body training, use the lower end of the Sunday dip range or reduce it another 5–10%.
